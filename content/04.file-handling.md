# File Handling
File handling is the process of creating, opening, reading, writing, appending, modifying, and deleting files. It allows programs to store data permanently so that the data can be accessed even after the program has finished running.

Python provides built-in functions that make working with files simple and efficient. Files can store different types of data, such as text, images, audio, videos, and other binary data.


## Opening a File
Python uses the built-in `open()` function to open a file and return a **file object**. The file object provides methods for reading from, writing to, and managing the file.

**Syntax**:
```python
file = open(file_name, mode, encoding, errors, newline)
```
- **file_name**(required): The name or path of the file to open. 
- **mode**(optional): Specifies how the file will be opened. The default mode is "r" (read mode).
- **encoding** (optional): Specifies the character encoding used when reading or writing text files (e.g., "utf-8").
- **errors** (optional): Specifies how encoding and decoding errors are handled.
- **newline** (optional): Controls how newline characters are handled in text mode.

>[!Note]
> The `encoding`, `errors`, and `newline` parameters are mainly used when working with **text files**. They are ignored in binary mode.

### File Modes
The mode determines how a file is opened and what operations can be performed on it.

| Mode | Description                                                         |
|------|---------------------------------------------------------------------|
| `r`  | Opens a file for **reading**. The file must already exist (Default mode)|
| `w`  | Opens a file for **writing**. If the file already exists, its contents are erased. If it does not exist, a new file is created |
| `a`  | Opens a file for **appending**. New data is added to the end of the file. If the file does not exist, it is created automatically |
| `r+` | Opens a file for both **reading and writing**. The file must already exist |
| `w+` | Opens a file for both **reading and writing**. Existing contents are erased, or a new file is created if it does not exist |
| `a+` | Opens a file for both **reading and appending**. New data is always written at the end of the file. The file is created if it does not exist|
| `x`  | Creates a new file for writing. Raises a `FileExistsError` if the file already exists.|


> [!Important]
> By default, Python opens files in **text mode**.
> - Add **`t`** to the mode to explicitly open a **text file** (e.g., `"rt"` or `"wt"`).
> - Add **`b`** to the mode to open a **binary file** (e.g., `"rb"` or `"wb"`).
> Since text mode is the default, `"r"` and `"rt"` have the same meaning.

**Examples**:
```python
# Open a text file for reading
file = open("example.txt", "r")

# Open a binary file for reading
file = open("image.jpg", "rb")

# Open a text file for writing
file = open("notes.txt", "w")
```

## Closing a File
After you finish working with a file, you should close it using the `close()` method.

Closing a file:
- Frees system resources.
- Ensures all buffered data is written to the file.
- Prevents accidental modifications.
- Allows other programs to access the file properly.

**Example**:
```python
file = open("example.txt", "r")  # Open file in read mode

content = file.read()            # Read file content
print(content)

file.close()                     # Close the file
```

> [!Warning]
> Forgetting to close a file may lead to resource leaks or data not being written correctly.


## The `with` Statement (Recommended)
When a file is opened using `with`, Python automatically closes the file after the block of code finishes executing, even if an exception occurs. This makes your code safer, cleaner, and easier to maintain.

**Syntax**:
```python
with open(file_name, mode) as file:
    # File operations
```

**Example**:
```python
with open("example.txt", "r") as file:
    content = file.read()
    print(content)
# File is automatically closed here
```


## Working with Text Files
A **text file** stores data as a sequence of readable characters. Examples include `.txt`, `.csv`, `.py`, `.html`, and `.json` files. Text files are opened in **text mode**, which is the default mode in Python. 


### Reading Files
Python provides several methods for reading data from a file.

| Method       | Parameters        | Description                                                      |
|--------------|-------------------|------------------------------------------------------------------|
| `read()`     | `size` (optional) | Reads data from a file and returns it as a string |
| `readline()` | `size` (optional) | Reads a single line from the file, including the newline character (`\n`) |
| `readlines()`| `size` (optional) | Reads all lines and returns them as a list of strings  |


> [!Note]
> The optional parameter specifies the maximum number of **characters** to read when working with text files.


**Examples**:
-  Read the entire file
```python
with open("example.txt", "r") as file:
    all_content = file.read()
    print("Full content:")
    print(all_content)
```

- Read file line by line
```
with open("example.txt", "r") as file:
    print("\nLine by line:")
    for line in file:
        print(line.strip())
```


### Writing to a File
Use the `write()` method to write text to a file. The method **accepts a string** and **returns the number of characters** written.

**Example**:
```python
# Writing to a file (overwriting content)
with open("example.txt", "w") as file:
    file.write("This is a new line of text.")

# Appending to a file (adds content at the end)
with open("example.txt", "a") as file:
    file.write("\nThis is an appended line.")
```

#### Writing Multiple Lines
You can call `write()` multiple times.

**Example**:
```python
with open("example.txt", "w") as file:
    file.write("Line 1\n")
    file.write("Line 2\n")
    file.write("Line 3\n")
```

### Common File Object Methods
Python file objects provide several useful methods.

| Method                | Description                                           |
|-----------------------|-------------------------------------------------------|
| `tell()` 	       | Returns the current position of the file pointer |
| `seek(offset)`   | Moves the file pointer to a specified position
| `flush()`	       | Immediately writes buffered data to the file |
| `readable()`     | Returns True if the file supports reading |
| `writable()`     | Returns True if the file supports writing |
| `seekable()`     | Returns True if the file pointer can be moved using `seek()` |


## Working with Binary Files
Binary files store raw bytes commonly used for images, audio files, videos, PDF documents, compressed files, and executable programs. When working with binary files, Python does **not** perform any character encoding or decoding. Instead, data is read and written exactly as it is stored.



### Reading Binary Files
Binary files use the same methods as text files, such as `read()`, `readline()`, and `readlines()`. However, these methods return **bytes** instead of strings.

**Example**:
```python
with open("image.jpg", "rb") as file:
    data = file.read()
    print(data)
```
The output begins with **`b`**, indicating that it is a **bytes object**.


#### Reading a Specific Number of Bytes
You can specify the maximum number of bytes to read.

**Example**:
```python
with open("image.jpg", "rb") as file:
    header = file.read(10)
    print(header)
```
This reads only the first **10 bytes** of the file.

> [!Important]
> - Avoid using `read()` without an argument on very large files, as it loads the entire file into memory.
> - Don't use this kind of read if you're not sure that the file's contents will fit the available memory.


## Writing Binary Files
To write binary data, open the file in `wb` mode.

The `write()` method accepts a **bytes object** or a **bytearray object** and returns the number of bytes written.

**Example**:
```python
data = b"Hello"

with open("data.bin", "wb") as file:
    file.write(data)
```


## The `bytes` Object

A `bytes` object represents an immutable sequence of bytes. Each byte is an integer in the **range 0 to 255**.

Once created, a `bytes` object cannot be modified.

**Example**:
```python
data = bytes([65, 66, 67, 68, 69])
```


### The `bytearray` Object

A `bytearray` is a mutable sequence of bytes. Like a bytes object, each element must be an **integer between 0 and 255**. However, unlike bytes, a **bytearray can be modified after it is created**.

`bytearray` objects are useful when processing binary data such as images, audio files, or network packets.



#### Creating a Bytearray
**Example**:
```python
buffer = bytearray([65, 66, 67, 68, 69])
```


#### Writing a Bytearray to a File
```python
# Create a byte array
byte_array = bytearray([65, 66, 67, 68, 69])  # Represents ASCII characters 'ABCDE'

# Open a binary file in write mode
with open("binary_file.bin", "wb") as file:
    # Write the byte array to the file
    file.write(byte_array)
```
The file will contain the binary representation of the ASCII characters `ABCDE`.




#### Reading into a Bytearray
The `readinto()` method reads bytes directly **into an existing buffer** instead of creating a new bytes object. This makes it more memory-efficient when reading large binary files.

**Syntax**:
```python
file.readinto(buffer)
```
- `buffer` must be a bytearray.
- The method returns the number of bytes read.

**Example**:
```python
# Open a file in binary read mode
with open("binary_file.bin", "rb") as file:
    # Create a bytearray to store the read bytes
    buffer = bytearray(10)  # Allocate a buffer of size 10

    # Read bytes into the buffer
    bytes_read = file.readinto(buffer)
```


## Checking File Existence
Sometimes, it’s necessary to check if a file exists before trying to open or modify it. This helps prevent errors such as `FileNotFoundError`.

Python provides two common ways to check file existence:

### 1. Using the `os` module
The `os.path.exists()` function returns `True` if the specified file or directory exists; otherwise, it returns `False`.

**Example**:
```python
import os

if os.path.exists("example.txt"):
    print("File exists!")
else:
    print("File does not exist.")
```


### 2. Using the `pathlib` module (recommended for modern Python)

The `pathlib` module provides an object-oriented way to work with file paths.

**Example**:
```python
from pathlib import Path

file = Path("example.txt")

if file.exists():
    print("File exists!")
else:
    print("File does not exist.")
```

> [!Note]
> `pathlib` is generally preferred over `os.path` because it is easier to read, more expressive, and more consistent across operating systems.



## Deleting a File
Python allows you to delete files using either the `os` module or the `pathlib` module. Deleting a file is permanent. Once a file is deleted, it usually cannot be recovered unless a backup exists.

**Examples**:
- Using the os Module
```python
import os

if os.path.exists("example.txt"):
    os.remove("example.txt")
    print("File deleted.")
else:
    print("File does not exist.")
```

- Using the pathlib Module
```python
from pathlib import Path

file = Path("example.txt")

if file.exists():
    file.unlink()
    print("File deleted.")
else:
    print("File does not exist.")
```


## File Exception Handling
Sometimes a file operation fails even if the file exists. For example:

- The file may not exist.
- You may not have permission to access it.
- The file may already be in use by another program.


### Common File Handling Errors
| Exception	           | Cause                                                      | 
|----------------------|------------------------------------------------------------|
| `FileNotFoundError`  |	The specified file does not exist                        |
| `PermissionError`    |	The program does not have permission to access the file  |
| `FileExistsError`    |	A file already exists when using "x" mode                |
| `IsADirectoryError`  |	A directory was opened as if it were a file              |
| `NotADirectoryError` |	Part of the specified path is not a directory            |


**Example**:
```python
try:
    with open("example.txt", "r") as file:
        print(file.read())

except FileNotFoundError:
    print("The file does not exist.")

except PermissionError:
    print("You do not have permission to access this file.")
```
