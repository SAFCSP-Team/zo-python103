# File handling

File handling is the process of performing operations like **reading**, **writing**, **appending**, and **modifying** files. Python provides built-in functions to work with files, making it simple and efficient.

## Key Operation

1. Open a file:

   Use the built-in `open()` function to open a file.
   ```python
   file = open("filename.txt", "mode")
   ```
   - `filename.txt`: Path or name of the file.
   - `mode`: Specifies the operation (read, write, append, etc.).

### File Modes
| Mode | Description                                      |
|------|--------------------------------------------------|
| `r`  | Read mode (default). Opens the file for reading |
| `w`  | Write mode. Overwrites if the file exists, or creates a new file |
| `a`  | Append mode. Adds new data at the end of the file |
| `r+` | Read and write mode (does not create a new file) |
| `w+`| Opens a file for reading and writing in text mode. It truncates the file if it exists or creates a new file|


Example

When opening a file, it’s important to close it after the operation to free system resources
```python
file = open("example.txt", "r")  # Open file in read mode
content = file.read()           # Read file content
print(content)
file.close()                    # Close the file
```

2. The `with` Statement:
   Using `with open(...)` ensures the file is automatically closed after the operation.

Example using `with`
```python
with open("example.txt", "r") as file:
    content = file.read()
    print(content)
# File is automatically closed here
```

### Reading Files

Python provides several methods to read files:
| Method         | Description                                      |
|----------------|--------------------------------------------------|
| `file.read()`  | Reads the entire file as a single string         |
| `file.readline()` | Reads a single line from the file             |
| `file.readlines()` | Reads all lines and returns them as a list  |

Example for reading a file
```python
with open("example.txt", "r") as file:
    # Read the entire file
    all_content = file.read()
    print("Full content:")
    print(all_content)

    # Read file line by line
    file.seek(0)  # Reset pointer to the start of the file
    print("\nLine by line:")
    for line in file:
        print(line.strip())
```

### Writing to a File
- `write()` method is used to write to a file.
- Opening a file in:
  - **`w` mode:** Overwrites the existing content or creates a new file.
  - **`a` mode:** Appends to the file without erasing existing content.

Example for writing and appending
```python
# Writing to a file (overwriting content)
with open("example.txt", "w") as file:
    file.write("This is a new line of text.")

# Appending to a file (adds content at the end)
with open("example.txt", "a") as file:
    file.write("\nThis is an appended line.")
```


### Common File Object Methods

| Method            | Description                                           |
|-------------------|-------------------------------------------------------|
| `file.read(size)` | Reads `size` number of characters (default: entire file) |
| `file.write(data)`| Writes the `data` string to the file                 |
| `file.readline()` | Reads the next line from the file                    |
| `file.readlines()`| Returns all lines as a list of strings               |
| `file.seek(offset)`| Moves the file pointer to the specified position     |
| `file.close()`    | Closes the file object                               |

## Working with Binary Files
To handle non-text files (e.g., images, videos), open them in binary mode (`rb`, `wb`, or `ab`).

Example for reading a binary file
```python
with open("image.jpg", "rb") as file:
    data = file.read()
    print(f"Read {len(data)} bytes from the file.")
```

## Working with Binary Files

Binary files are used to store non-text data such as images, videos, and other types of binary data. To handle binary files, Python provides modes like `rb` (read binary), `wb` (write binary), and `ab` (append binary).

>[!Important]
> - Binary files deal with raw byte data.
> - The content of a binary file is an **array of bytes**.
> - You cannot assign values that lie outside the range **0 to 255**, as each byte can only represent numbers within this range.


Example for writing a byte array to a binary file

Here’s how to create a byte array and write it to a binary file:
```python
# Create a byte array
byte_array = bytearray([65, 66, 67, 68, 69])  # Represents ASCII characters 'ABCDE'

# Open a binary file in write mode
with open("binary_file.bin", "wb") as file:
    # Write the byte array to the file
    file.write(byte_array)
```

Explanation:
1. Create a `bytearray`:
   - Each value must be from 0 to 255, inclusive.
   - In the example, `[65, 66, 67, 68, 69]` corresponds to the ASCII codes for `'A', 'B', 'C', 'D', 'E'`.
   
2. Open the File:
   - File is created using `open()` with the `"wb"` mode (write binary).

3. Write the Byte Array:
   - The `write()` method sends the byte array data to the file.


#### Reading a Binary File
Binary files are read as a series of bytes. Here's how to read a binary file:
```python
with open("binary_file.bin", "rb") as file:
    data = file.read()
    print(data)  # Outputs: b'ABCDE'
```


## Checking File Existence
Sometimes, it’s necessary to check if a file exists before trying to open or modify it. You can use the `os` or `pathlib` module.

Example for checking file existence
```python
import os

if os.path.exists("example.txt"):
    print("File exists!")
else:
    print("File does not exist.")
```


## Deleting a File
You can delete a file using the `os` module.

Example for deleting a file
```python
import os

if os.path.exists("example.txt"):
    os.remove("example.txt")
    print("File deleted!")
else:
    print("File does not exist.")
```
