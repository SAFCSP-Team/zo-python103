# Metaclass

Metaclasses are one of Python's most advanced features. They can seem mysterious because most Python programmers use them without realizing it. However, understanding metaclasses helps you understand how Python itself works because **everything in Python is an object**, including classes. Just as an object is an instance of a class, a class is an instance of a **metaclass**. 



## What is a Metaclass?
A **metaclass** is a class whose instances are classes.

When you write:
```python
class Person:
    pass
```

Python creates an object called `Person`, which is an instance of `type`.
```python
print(type(Person))   # <class 'type'>
```

Now create an instance of `Person`:
```python
p = Person()

print(type(p))   # <class '__main__.Person'>
```

There are therefore two different relationships:

- `p` is an instance of `Person`.
- `Person` is an instance of `type`.


The relationship can be visualized like this:

```text
Object  ──created by──► Class
Class   ──created by──► Metaclass
```
- A normal class controls the creation and behavior of its **instances**.
- A metaclass controls the creation and behavior of its **classes**



When Python processes a class definition, it does not create the class directly. Instead, it requests a metaclass to construct it. By default, Python uses the built-in metaclass called **`type`**. So, the complete hierarchy is structured as follows:

```
Metaclass (type)
        │
        ▼
Class (Person)
        │
        ▼
Object (person)
```

### Why Use Metaclasses?
Metaclasses are useful when you want to customize **how classes are created**, rather than customizing the behavior of their instances.

Common uses include:
- Automatically registering classes
- Validating class definitions
- Enforcing rules on classes
- Automatically adding methods or attributes
- Building frameworks and libraries
- Implementing plugin systems
- Customizing class creation




## The `type` Function
Most programmers know `type()` only as a function for checking types.

```python
type(10)        # <class 'int'>

type("hello")   # <class 'str'>
```

However, `type` is also a class and can be used to create classes.

It has a three-argument form:

```python
type(name, bases_classes, namespace)
```

**Example**

```python
Person = type(
    "Person",
    (),
    {}
)
```

This creates a simple class named `Person`. It is approximately equivalent to:

```python
class Person:
    pass
```

The two approaches are not identical in every detail. A `class` statement performs additional work, including executing the class body, handling decorators, determining the metaclass, and supporting other class-creation features.


## Creating Classes Dynamically
Because classes are objects, Python can create them dynamically at runtime. Instead of using the `class` keyword, you can create classes using `type()`:

**Syntax**:
```python
type(name, bases_classes, namespace)
```
- `name`: The name of the class.
- `base_classes`: A tuple containing the parent classes `(object,)` or if there are no parents `()`.
- `namespace`: A dictionary containing all class attributes and methods.

**Example**
```python
class Person:
    country = "KSA"

    def greet(self):
        print("Hello")
```

A similar class can be created dynamically with `type()`:

```python
def greet(self):
    print("Hello")


Person = type(
    "Person",
    (),
    {
        "country": "KSA",
        "greet": greet,
    }
)
```


## How Python Creates a Class

When Python encounters:

```python
class Person:
    pass
```

It does **not** immediately create the class. Instead, it performs several steps.

1. Determine which metaclass should create the class. If no metaclass is specified, it uses `type`.
2. Create a namespace for the class body.
3. Execute the class body in that namespace.
4. Call the metaclass to create the class object.
5. Initialize the newly created class object.
6. Assign the resulting class object to the variable named `Person`.


### The Metaclass Lifecycle

The process of creating a class or instance of that class involves several special methods.

**Creating a class**:
```
class statement
        │
        ▼
Metaclass.__prepare__()   
        │
        ▼
Execute class body
        │
        ▼
Metaclass.__new__()
        │
        ▼
Metaclass.__init__()
        │
        ▼
Class object created
```  


**Creating an instance**:
```
   class_name() 
        │
        ▼
Metaclass.__call__()
        │
        ├──► class.__new__()
        │
        └──► class.__init__()
        │
        ▼
   class instance
```
Each method has a specific purpose.


## `__prepare__()`

`__prepare__()` is called **before** Python executes the class body. Its purpose is to provide the namespace that will be used while the class body executes.


**Example**
```python
def __prepare__(metacls, name, bases):
    ...
    return {}
```

Most applications don't need to override the `__prepare__()` method, but it can be helpful for custom mappings or managing name assignments during class creation. Custom namespaces were once crucial for preserving the order of definitions, but with Python 3.7 and later, standard dictionaries maintain insertion order by default.


## `__new__()` 
A metaclass's `__new__()` method is responsible for creating the **class object**.

This is an important distinction:
- A metaclass's `__new__()` creates a **class object**.
- A class's `__new__()` creates an **instance object**.

**Example**
```python
    def __new__(cls, name, bases_classes, namespace):
        print("Building class")
        namespace["language"] = "Python"
        return super().__new__(cls, name, bases_classes, namespace)
```
- `cls`: the metaclass itself.

Every class now automatically receives a `language` attribute because the metaclass modified the namespace before the class object was created.


## `__init__()` 
After the metaclass's `__new__()` creates the class object, the metaclass's `__init__()` can initialize that class object. This is useful for setup tasks that don't require modifying the namespace before class creation.

**Example**
```python
    def __init__(cls, name, bases, namespace):
        print("Initializing:", name)

        super().__init__(name, bases, namespace)
```


## `__call__()`
Normally, creating an object looks like calling the class.

```python
person = Person()
```

Behind the scenes, Python actually calls:
```python
type(Person).__call__(Person)
```
Since `Person` is an instance of the metaclass, `__call__` is defined by the metaclass. By default, `type.__call__()` performs three steps:

1. Call the class's `__new__()`.
2. Call the class's `__init__()`.
3. Return the new instance.

This means a custom metaclass can override `__call__()` to customize what happens when the class is called.




## Creating a Custom Metaclass
A custom metaclass is simply a class that inherits from `type`.

**Syntax**:
```python
class MyMeta(type):
    pass
```

A class can then specify it with the `metaclass` keyword:
```python
class Person(metaclass=MyMeta):
    pass
```
Now Python uses `MyMeta` to create `Person` instead of the default `type`.

**Example**
```python
class MyMeta(type):

    def __new__(cls, name, bases, namespace):
        print("1. Metaclass __new__")
        return super().__new__(cls, name, bases, namespace)

    def __init__(cls, name, bases, namespace):
        print("2. Metaclass __init__")
        super().__init__(name, bases, namespace)

    def __call__(cls, *args, **kwargs):
        print("3. Metaclass __call__")
        return super().__call__(*args, **kwargs)


class Person(metaclass=MyMeta):

    def __new__(cls):
        print("4. Person __new__")
        return super().__new__(cls)

    def __init__(self):
        print("5. Person __init__")


person = Person()
```

Output:

```text
1. Metaclass __new__
2. Metaclass __init__
3. Metaclass __call__
4. Person __new__
5. Person __init__
```

Notice the two different stages.

#### Stage 1: Creating the class

```text
MyMeta.__new__()
       ↓
MyMeta.__init__()
       ↓
Person class object created
```

#### Stage 2: Creating an instance

```text
MyMeta.__call__()
       ↓
Person.__new__()
       ↓
Person.__init__()
       ↓
person instance created 
```
